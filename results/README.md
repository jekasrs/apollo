# Результаты экспериментов

Сюда складываются **чекпоинты**, **логи** и **сводки** по прогонам.

## Именование папки прогона

Рекомендуемый шаблон:

```text
{модель}_{датасет}_{модальность}_e{номер_эксперимента}_r{попытка}
```

Примеры:

- `apollo_meld_at_r01` — Apollo, MELD, модальность `at`, первая попытка (дефолт в `train.py`)
- `apollo_iemocap_at_r01` — тот же стек на IEMOCAP
- `apollo_meld_a_r01` — только аудио

Допускаются короткие суффиксы (`_grid`, `_pause_search`), если так удобнее для скриптов.

## Содержимое одной папки

| Файл | Описание |
|------|----------|
| `model.pt` | Итоговый чекпоинт от `train.py` (`best_state`, метаданные) |
| `best_dev_f1_model_.pt` | Снимок весов при лучшем dev внутри одной эпохи (пишет `Coach`) |
| `train.log` / копии логов | По желанию |

Дообученные **энкодеры** (не тот же артефакт, что Apollo) лежат отдельно:

- `results/encoders/finetune_mpnet_meld/`
- `results/encoders/finetune_wav2vec_meld/`

Их подхватывает препроцесс, если не заданы `APOLLO_FINETUNED_TEXT` / `APOLLO_FINETUNED_WAV2VEC`.
