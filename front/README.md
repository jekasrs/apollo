# Eleos — веб-интерфейс

Краткое описание: статическая оболочка **Eleos** для проекта Apollo — составление многоходового диалога, отправка на сервер и визуализация предсказанных эмоций по репликам (модель в `back/`).

## Возможности

- Создание диалога: число участников (до 32), реплики с выбором говорящего, демо-текст по умолчанию, кнопка «Новый чат».
- Анализ: запрос к API, цепочка реплик в виде графа (SVG), легенда эмоций, сводка по каждому участнику (тон и распределение по 7 классам).
- Импорт и экспорт JSON в формате `eleos-dialogue-v1` (поддерживается и устаревший `apollo-dialogue-v1`).
- Индикатор готовности модели через `/api/status` (чекпоинт, ошибка загрузки).

## Структура каталога

| Файл | Назначение |
|------|------------|
| `index.html` | Разметка страницы, подключение `/static/style.css` и `/static/app.js`. |
| `app.js` | Логика UI, работа с JSON, `fetch` к `/api/status` и `/api/analyze`, отрисовка SVG-графа. |
| `style.css` | Тема интерфейса, сетка панелей, стили чата и блока результата. |

Файлы отдаются приложением FastAPI не из текущего пути в URL, а с префиксом **`/static/`** (см. `back/app/main.py`). Главная страница открывается по **`/`** того же сервера.

## Зависимости

У **фронтенда** нет собственных пакетов: только HTML, CSS и JavaScript в браузере.

Нужен **бэкенд** репозитория (Python, FastAPI, зависимости из корневого `requirements.txt`, см. [README в корне](../README.md)).

## Как запустить

1. Из **корня репозитория** (где лежат `front/` и `back/`):

   ```bash
   pip install -r requirements.txt
   PYTHONPATH=back uvicorn app.main:app --host 127.0.0.1 --port 8765
   ```

   Альтернатива из каталога `back/`:

   ```bash
   cd back && pip install -r ../requirements.txt
   PYTHONPATH=. uvicorn app.main:app --host 127.0.0.1 --port 8765
   ```

2. Откройте в браузере: [http://127.0.0.1:8765/](http://127.0.0.1:8765/).

По умолчанию ожидается чекпоинт `results/apollo_meld_at_r01/model.pt`. Другой файл: `export APOLLO_CHECKPOINT=/путь/к/model.pt` перед запуском uvicorn.

**Важно:** открытие `index.html` как локального файла (`file://`) не подойдёт — пути `/static/...` и `/api/...` рассчитаны на тот же хост и порт, что и API.
