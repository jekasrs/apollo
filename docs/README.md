# Apollo — документация

### Решаемая задача

Для каждой реплики диалога требуется предсказать дискретную эмоцию из фиксированного множества классов.

### Структура `docs/`

| Каталог / файл | Назначение |
|----------------|------------|
| `diagrams/` | Диаграммы (drawio XML, блок-схемы, экспорт) |
| `images/` | Скриншоты, графики, `arch.png` и т.п. |

### Архитектура

1. Мультимодальные признаки: текст (768) и аудио (768, усреднённый выход Wav2Vec2), режимы `a` / `t` / `at`. Пересборка `samples.pkl`: `PYTHONPATH=. python dataset/preprocess/preprocess.py` (или путь из вашего окружения).
2. Двухслойный BiLSTM по контексту до/после реплики.
3. Графовая сеть (RGCNConv + TransformerConv): связи между репликами и спикерами.
4. MLP-классификатор.

Схему архитектуры при необходимости положите в `images/` (например `images/arch.png`) и вставьте в отчёт: `![](./images/arch.png)`.
